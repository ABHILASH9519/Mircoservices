# Microservices

A workspace for new, self-contained microservice projects. Each project lives in its own directory directly under this repository.

## Projects

| Project | Description | Status |
|---|---|---|
| [Project Relay](Project-Relay/) | Cross-Application Transaction Network | Project directory created |

## Organization

Every project owns its service code, README, dependency manifests, environment examples, configuration, Dockerfiles, and deployment assets as required. Build and launch commands belong within the individual project folder. Add each new project at the root level alongside `Project-Relay/`.
